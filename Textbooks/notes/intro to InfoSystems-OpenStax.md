# 1.1 Intro to Information System #
- connects technology and information by collecting, analyzing, maintaining, and distributing data to support decision-making, coordination, and other functions of orgs.

### Components ###
1. Hardware
   - physical devices; computers, servers networks, storage devices.
2. Software
   - programs and apps that run on hardware. can be an OS, database, and special apps.
3. Data
   - raw facts and figures; collected and processed to create *information* - which is used to make key decisions and draw insights
4. Procedure
   - sets of instructions/rules to govern the use the above components
5. People
   - everyone; ranging from end users who interact with systems to the designers who develop and maintain the system.

### Elements ###
1. Environment
   - physical location and/or network capabilities. must adapt depending on requirements of system (physical location, cybersecurity practices).
2. Input
   - the data that is collected and entered into a system, eitehr via users or automatically on events. most IS need multiple software apps to handle diverse types of data (quant vs. qual).
3. Processing
   - taking data and making it useful in a system.
4. Output
   - data that a system generates and provides to users
5. Cotrols
   - policy/procedures ensuring system functions effectively and securely.
        * application control - built into a system; firewalls, encryption, access control
        * general control - process that outlines how an IS is to be used
### Operations ###

1. Data capture
   - process of gathering data from various sources, and inputting into a system
2. Data processing
   - cleaning, preparing, and analysis to transform data into meaningful insights.
3. Data storage
   - maintaining data, storing and protecting data in secure sites
4. Data retrieval
   - users should be ale to load and review applications that store data, download and is use for various purposes.
5. Data dissemination
   - the process of sharing information

### Types of information systems ###
1. Executive (Strategic) [C-suite]
   - Top of the pyramid, where c-suites live. Develop strategic goals and functions.
   - i.e Supply Chain management
2. Descision support (tactical) [SVP/BU leaders]
   - data analysis heavy role, responsible for repititve analysis and quick descion making of operations.
   - i.e project management, onboarding/training
3. Management IS (Managerial) [Directors]
   - generate reports, budgets, cash flow, etc. Provide data for orginization across various functions. helps build  *Balance Scorecard* (BSC).
4. Transaction processing (Operational) [Consultants]
   - day-to-day transactions, order processing to payroll, this provides info necessary to handle daily ops. 

* ERP  - Enterprise resource planning system
   - software system that helps manage various info systems in an org. Integrates business funtions across orgs, i.e payroll, customer service
 

# 1.2 Frameworks of Knowledge and Industry Standards #

- Framework: tangible structured set set of guidelines and best practices
- Standards: widely accepted and implemented techniques

Types:
1. **Agile**
   - *Framework*
        - divides projects into sprints
        - review after each sprint before moving to next
        - sprints include planning, designing, developing, testing, deploying
2. **Control objectives for Information and Related Tech (COBIT)**
   - *Framework*
        - 5 methodologies; revolving around GOVERNANCE: 1) Evaluate, Direct, Monitor (EDM)
      MANAGEMENT:
      2) **APO** - Agile Plan Organize [Plan] <-- Direct
        3) **BAI** - Build Acquire Implement [Build]
         4) **DSS** - Deliver Service Support [Run]
           5) **MEA** - Monitor Evaluate Asses [Monitor] --> Monitor
